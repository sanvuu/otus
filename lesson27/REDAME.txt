## 2. Практическая реализация
* Инфраструктура разворачивается на базе **Ubuntu 24.04 LTS (Bento box)** в провайдере Libvirt/KVM.
* Сетевые настройки и статические маршруты полностью автоматизированы через **Ansible роли** и **Netplan конфигурации**.
* На хостах отключено автоматическое назначение дефолтных шлюзов на интерфейсе управления `eth0`.
* На `inetRouter` поднят и настроен NAT (`nftables`) для маскарадинга внутренних сетей наружу.

## 3. Инструкция по запуску стенда
```bash
# 1. Сборка и старт виртуальных машин
vagrant up --no-parallel

# 2. Итоговое тестирование связи с сервера office1Server
vagrant ssh office1Server -c "ip route show && ping -c 3 ya.ru"
```
