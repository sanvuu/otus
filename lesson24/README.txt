# Домашнее задание: Сбор логов и подсистема аудита

### Описание стенда:
Инфраструктура разворачивается с помощью Vagrant и настраивается через Ansible. Состоит из двух машин:
1. **web (192.168.56.10)** — Веб-сервер Nginx. Настроена отправка системных логов, логов Nginx и логов безопасности (Auditd) на удаленный сервер.
2. **log (192.168.56.15)** — Центральный сервер сбора логов. Настроен Rsyslog для приема логов по UDP/TCP на порту 514 с распределением логов клиентов по каталогам `/var/log/rsyslog/%HOSTNAME%/`.

### Как запустить:
```bash
vagrant up
```
*Все настройки сети, проброс портов, копирование ключей между машинами и развертывание сервисов происходят автоматически.*

### Проверка работоспособности стенда:
При перезапуске сервисов или генерации событий на машине `web`, на сервере `log` успешно создается директория `/var/log/rsyslog/web/`, куда в реальном времени записываются файлы логов:
- `nginx_access` и `nginx_error`
- Системный журнал `syslog`
- Логи аудита `auditd`
